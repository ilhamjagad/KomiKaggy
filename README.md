# 📖 KomiKaggy

**KomiKaggy** adalah aplikasi web baca komik, manga, manhua, dan manhwa modern berbasis Bahasa Indonesia. Didesain dengan antarmuka yang bersih, responsif, hemat data, serta bebas dari iklan yang mengganggu.

---

## ✨ Fitur Utama

- 🚀 **Performa Cepat**: Dibangun menggunakan Next.js App Router untuk navigasi halaman yang instan.
- 📱 **Desain Responsif**: Tampilan nyaman diakses dari smartphone, tablet, maupun desktop.
- 🕒 **Riwayat Baca (History)**: Menyimpan otomatis chapter terakhir yang dibaca menggunakan `localStorage`.
- 🔍 **Pencarian & Filtering**: Pencarian judul komik cepat dan filter chapter berdasarkan urutan (Terbaru/Terlama).
- 🎨 **UI Modern & Dark Mode**: Tampilan serba gelap yang nyaman di mata untuk membaca waktu lama.

---

## 🛠️ Teknologi yang Digunakan

- **Framework**: [Next.js](https://nextjs.org/) (App Router)
- **Library**: [React](https://react.dev/)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
- **Deployment**: [Vercel](https://vercel.com/)
